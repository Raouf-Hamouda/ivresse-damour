Pour passer le site dessus

Ecrit ici, PAS applique. Le basculement est la decision de Raouf. Deux choses a coller, dans cet ordre.

@font-face{
  font-family:'Ivresse Titre';
  src:url('assets/fonts/titre/IvresseTitre-Regular.woff2') format('woff2'),
      url('assets/fonts/titre/IvresseTitre-Regular.otf') format('opentype');
  font-weight:400; font-style:normal; font-display:swap;
}
/* dans assets/css/site.css, la seule ligne a changer : */
:root{ --font-titre:'Ivresse Titre', Georgia, serif; }

Sans fichier de police, la meme chose se fait en JavaScript : <script src="assets/fonts/titre/alphabet_titre.js"></script> puis svg.innerHTML = titreTexte({text:"IVRESSE D'AMOUR", size:72, x:0, y:80}).
